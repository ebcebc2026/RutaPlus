RUTA PLUS

Archivos principales:
- index.html + index.js: página de inicio y búsqueda.
- rutas.html + rutas.js: consulta, comparación y guardado de rutas.
- alertas.html + alertas.js: alertas y reporte de incidentes.
- styles.css: diseño responsivo compartido.

Cómo abrir el proyecto:
1. Abre la carpeta ruta-plus en Visual Studio Code.
2. Instala la extensión Live Server si todavía no la tienes.
3. Haz clic derecho en index.html.
4. Selecciona "Open with Live Server".

La información se guarda en localStorage. Bootstrap y Bootstrap Icons se cargan mediante CDN, por lo que se necesita conexión a internet para verlos.
